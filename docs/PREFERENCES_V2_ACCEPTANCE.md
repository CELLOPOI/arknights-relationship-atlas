V2 原验收采用每周120、连续28天480、每人物28天3次；2026-09-25 调整为每周300、连续28天1,200、每人物28天6次（[现行口径](PREFERENCES.md)），无序对位防重复延长到84天。50次休息提示与统计K独立配置，可以直接继续。未知结果保留原任务/对象、参数、操作键；跨入口卸载或迟到响应不会新派题、重扣额或串写另一个对象。搜索、职业、草稿、滚动与历史可恢复。

首页→人物关系→游戏→喜好→来源使用统一顺序，正向/反向点击、历史与边界手势方向相反。真实CDP触控、原生滚轮、减少动画均验证；长列表正常滚动，输入、弹窗、图谱缩放不被换页劫持。横屏回归发现确认栏遮住图片重试，已改为矮视口随内容滚动并复验。

## 算法与实际模拟

随机84/28天分别完整去重：同标识、无序对位保留最新有效明确判断，原记录不删除。对称 `min(1,50/n_u,1/d_ui,1/d_uj)` 同时进入BT胜场与比较边；每标识窗口总贡献≤50、每人物直接贡献≤1，单题权重1。组bootstrap每份副本保留预计算权重。联合样本、ESS、网络与稳定性门槛替代首版单纯原始条数门槛。

综合指数使用同一合格参照池内近84天随机分百分位70% + 当前支持百分位30%；本命单列，搜索不改变参照池。冷启动不补假分，资格不足只保留分项。快照保存参数、池、名录、素材及修订；7/28天变化及连线只在同口径，旧快照不覆盖。

实际模拟为600标识、12,000判断、32已知强度人物、200次组bootstrap：序关系恢复96.77%，平均分数误差1.689/100，单次区间覆盖28/32。另在581人物宽池验证K=25/50/100均实际绑定；跨周同人物追加1,440判断的直接贡献仍≤1，目标分变化约0.236；120新标识集中参与仍移动约20.504分。70/30百分位相对60/40、80/20最大移动4、3名，5行显示权重敏感。详见[统计定义、校准及限制](PREFERENCES_STATISTICS.md)和[冻结模拟报告](../data/preferences/simulation-v2.json)。

K/L、0.5先验和70/30保留为可解释产品取舍，不称最优或最公平；87.5%的单次区间覆盖不能证明总体95%覆盖。贡献封顶不等于最终分数影响封顶，匿名身份仍无法阻止集中创建新身份。公开页面没有注入合成成熟榜，真实低样本保持积累状态。
