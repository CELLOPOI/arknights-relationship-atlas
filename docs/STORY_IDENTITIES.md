# 同名人物与剧情补录

人物搜索别名与剧情身份判定有不同职责。“医生”既是彩虹干员代号，也可能是职业称谓；“费尔南”同时指向不同故事中的不同人物。全站搜索继续保留别名，候选生成只在已核对的来源范围内将这些歧义称呼绑定到干员。范围外的命中保留为待核线索，不能用于确定配对；联合说话者中有未确认身份时也不返回部分合声。

相邻资料工程的 `scoped-identity.mjs` 实施来源约束，干员扫描及 NPC 原文预处理共同使用它。已冻结的词法匹配器、原始剧情、人工审读及输入哈希保持可追溯；旧全文搜索仍可召回线索，不能独立证明身份。后续出现新剧情时，先核对身份，再扩充适用来源。

网站派生包使用 [修订清单](../data/corrections/story-identities-20260926.json) 和 [修订模块](../scripts/identity-corrections.mjs)。本批撤下 8 条误认关系，替换凯尔希与彩虹医生的错误剧情依据，并补录塔露拉与死芒双向认识。凯尔希与医生沿用已确认的人工裁定，证据明确标注为人工说明，不伪造剧情引文。

死芒的客观履历确认其本名为爱布拉娜·都柏林。主线 13-22《灾厄积渐》701–732 行包含两人的交手及直接对话：爱布拉娜点明塔露拉身份，塔露拉回应并识别深池的德拉克。相识只表示互相认识，不表示友好。补录使用现有人物 ID，并保存剧情与身份档案的来源摘要。

## 生成与正式发布

派生修订先比对原关系和完整证据的 SHA-256；输入发生变化时停止，要求重新核查，避免撤除后来补充的有效依据。重复应用保持相同结果。新关系已存在但内容不同也会停止。干员子集不包含塔露拉，只有双方都在图中的完整模式才加入该边。被撤下的上游贡献另存 `withdrawn-provenance.json`，原始审读文件保留。

生成器不写正式数据库。`data/source/` 和 `data/npc/` 仍是历史初始化或归档输入，不通过直接修改这些文件冒充线上修复。正式修订必须走[后台资料流程](EDITORIAL_WORKFLOW.md)：撤下错误关系及其证据，保留稳定 ID 和历史；新相识关系创建新的关系及证据记录。线上存在不同证据或待处理草稿时，应在后台核查，不能强制覆盖。

## 验证

- `make check` 包含清单的范围、幂等和旧内容保护验证。
- `make test-upstream` 需要相邻资料工程，检查既有原文及完整 NPC 派生包。
- 上游来源范围测试使用真实正反例：彩虹干员的剧情、普通医生、两位费尔南及联合说话者。
- 正式服务另行验证创建修订、审核、预览、事务发布、重复执行、回退及并发基线变化；本地验证不能证明生产已更新。
