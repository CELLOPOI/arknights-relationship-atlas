# 关系来源名称

关系详情接口在读取已发布证据时补充可读标题，图谱、关系档案和游戏中的关系依据共用这份结果。名称默认显示；“原始记录”保留来源字符串、起止行和原版本。经 PRTS 核对的条目提供对应剧情、任务目录或留言页面链接。

正式证据仍以数据库中的原始 `sources` 为准。标题属于辅助定位信息，不写回正式资料，不改变发布摘要、关系方向、原文或条件叙事。实现取舍见[来源名称索引决定](../.agents/notes/implemented/architecture/2026-09-21-source-titles.md)。

## 覆盖与依据

2026-09-21 核对本地初始化基线的 5,711 条证据：6,944 次剧情引用、814 次个人资料引用、10 次人工复核引用均有可读出处。规范化后共 1,952 个索引键；原始完整路径和相对路径仍原样返回。此计数不是当前业务数据库的实时统计。

名称主要来自游戏提交 `0ef7f952dfd018392200157a5c79a6511ba69122` 的配置：

| 来源 | 定位方式 |
| --- | --- |
| 活动、主线、密录 | `story_review_table` 的脚本、关卡编号、标题与分段标签；密录关联所属干员 |
| 隐藏剧情、梗概 | 剧情回顾附加表；梗概与正文保持独立标注 |
| 集成战略 | 主题、结局、结局后记、月度小队或月度故事及段次 |
| 生息演算 | 主题、章节任务、关卡及对话片段；补充配置保存已核对的对话到任务对应 |
| 教程 | 从关卡脚本引用反查实际关卡配置；无独立标题时标为“关卡内教学” |
| 档案、语音、模组、时装、信物 | 对应干员及配置中的正式名称 |
| 附加语音 | 《慈悲灯塔》尘封密室、特蕾西娅留言「启航纪念」及语音段次 |

PRTS 的公开 `story` 目录提供脚本路径到页面的对应。特殊活动名称和分支分别核对了[剧情导航](https://prts.wiki/w/模板:剧情导航)、[《泰拉 说唱之夜！》](https://prts.wiki/w/APF-2021/NBT)、[15-17 的分支](https://prts.wiki/w/15-17_“她”/END/SP1)。生息演算任务对照[沙洲遗闻日志](https://prts.wiki/w/沙洲遗闻/日志)与[重启锚点日志](https://prts.wiki/w/重启锚点/日志)，附加语音对照[尘封密室](https://prts.wiki/w/关卡一览/主题曲/尘封密室)。网页链接不代替保存的本地游戏版本及证据行号。

“对话前段／后段”“关卡内教学”“任务完成后对话”等是定位说明，不冒充独立官方剧情标题。`training_6_c` 的脚本头仍标为训练关卡 6c，但当前关卡配置未引用它，因此单列为 TR-6 的“教学补充片段”，不声称仍会在当前游戏中触发。

## 维护

`scripts/build-source-titles.mjs` 从指定游戏数据和资料快照生成 `backend/atlas/data/source-titles.json`。`scripts/source-title-supplements.json` 保存特殊活动、任务关联、分支、已核对 PRTS 页面和核对日期；生成结果保存输入文件 SHA-256、游戏提交及每条名称的依据。构建、启动和普通检查均读取已提交索引，不依赖相邻工程或联网。

在仓库根目录重建：

```bash
ARKNIGHTS_SOURCE_COMMIT=$(git -C ../ArknightsGameData rev-parse HEAD) node scripts/build-source-titles.mjs ../ArknightsGameData
```

参数依次为游戏数据目录、资料快照目录和输出文件。后两项默认是 `data/source` 与上述后端索引；也可对后台导出的快照生成候选索引，核对差异后随代码交付。命令不查询、不写入业务库，也不修改输入工程。未定位的来源、同一路径的冲突标题、未经复核的新游戏提交均使生成失败。

接口只给命中索引、且未指定其他版本的引用补充标题；明确声明不同版本或尚未收录的来源仍显示原始字符串。更新游戏版本或新增来源时重新核对并生成索引，不能借此覆盖后台已发布资料。

验证入口：`make check`；后端测试覆盖全基线命中、原始字段不变、非本版本与未知来源回退，以及未公开证据不泄露。`scripts/verify-source-titles.mjs` 用隔离 API 检查桌面与手机的三个展示入口、原始记录展开、外链及长路径换行。
