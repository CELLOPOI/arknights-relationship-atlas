## 数据维护

`scripts/faction-overrides.json` 只补充这六位人物在游戏角色表中缺失的阵营字段，避免重新导出时退回未归属；其他缺失人物仍需单独确认。静态快照已同步，数据库迁移 `0002_rhodes_elite_factions` 修正已有数据，并为每位人物增加修订号和一条变更记录。迁移仅处理指定 ID 且当前仍未归属的人物，不覆盖后台已修改的其他归属，不改变人物 ID、收藏或关系。

联动父级属于浏览导航，不新增数据库阵营，也不合并四支小队的人物资料。URL 使用 `group=collaboration` 保留所在目录；旧的小队 `faction` 链接也能正确返回联动目录。Vue 与静态原型均已同步。

## 验证

执行 `make check` 与专用测试库上的 `make check-postgres`，检查迁移重复执行、修订记录、已有编辑保护和收藏保留。资料比对须确认仅指定人物归属和空阵营条目变化，人物 ID、关系与证据不变。
