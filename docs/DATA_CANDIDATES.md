# 资料候选与修订条目

日常编辑入口为 [后台资料维护](EDITORIAL_WORKFLOW.md)。一份“资料修订”可包含多个人物、阵营、身份映射、关系和独立证据，整体审核后直接发布，无需导出资料 PR。

条目表单沿用原候选字段与来源编辑器，新增条目可以引用同一修订中的新人物或关系。保存草稿不修改正式资料；提交审核时统一验证引用、原文、公开状态及知晓方向。正式 ID、已有关系端点及已有证据归属继续受保护。

旧的独立候选不因数据库迁移被删除。进入详情选择“创建修订并加入此候选”，补充修改说明后继续编辑、审核与发布。原有候选版本和编辑历史保留。未归入修订的候选仍可下载备份；下载不构成发布，归入修订后只能通过整批发布导出正式快照。

同一条目保存核对候选版本和修订版本；待审核、已通过和已发布的修订不允许修改。后台其他发布改变基线时，按[版本冲突说明](EDITORIAL_WORKFLOW.md#版本冲突)处理。私有备注、编辑账号与历史不进入公开资料快照。
