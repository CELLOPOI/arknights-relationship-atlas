# 泡泡动态与连线

2026-09-20，用户选择轻盈漂浮，以及组内自由聚拢并保留分页。人物和折叠分组小幅缓慢浮动；展开组时，成员从原分组位置散开，附带650ms内清除的少量粒子。组内采用错列、不同排数和轻微错位，保留姓名、名录与分页。返回总览恢复布局锚点与视角。

拖动时头像跟随指针，松手短暂回弹，停留在用户放置的新位置。悬停或键盘聚焦的头像固定在当前位置，方便点击；正在入场的节点先完成过渡，避免被经过的鼠标冻结在其他人物旁。快速翻页和切换会以当前显示位置衔接，旧粒子不残留。

按用户对姓名起伏的反馈，文字与泡泡分开绘制：姓名、分组名称和人数保持在稳定的布局位置，仅头像与圆框参与持续漂浮和松手回弹。展开、翻页和拖动时，文字正常跟随位置变化；切换快照分别读取文字与头像的位置，连线端点继续跟随头像。不要再把持续漂浮直接施加到包含姓名的整个节点上。

连线采用按需显示：默认保留少量聚合关系，悬停或键盘聚焦人物时显示对应曲线。上方“显示选项”提供“全部连线”“周围关系”和“泡泡动态”。全部连线显示当前画布中实际关系，周围关系增加已显示人物之间的关系；没有创建装饰性假关系。相识类型、方向和原文仍以关系详情为准。手机可开启全部连线或使用名录查阅关系。

`frontend/src/atlas/graph-motion.js` 管理显示位置和曲线，`graph.js` 保存布局、手动拖动、分页和相机。动画不回写 `positions`，不通过刷新把浮动累积到布局。版本3使旧行列布局坐标失效；人物链接和正式资料不变。曲线端点与头像由同一动画帧绘制，隐藏的线不做逐帧路径更新。大于120个可见节点时限制绘制频率；全量显线的复杂度仍随实际边数增加。

关闭泡泡动态后停止动画循环，选择在本机浏览器保存；系统减少动态时直接使用静态布局。离开图谱、页面隐藏或画布不可见时暂停，重新可见后恢复。入场动画不阻塞导航，低高度横屏保留头像点击空间。没有新增运行时依赖或改动全站字体、颜色体系。

首页与侧栏的装饰性口号已删除；收藏空状态和登录引导改为具体操作说明。后续网页的文案约束位于根目录 [AGENTS.md](../AGENTS.md)。
