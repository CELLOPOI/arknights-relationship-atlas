# 喜好统计口径与校准

实现为 `preference_algorithm.py`、`preference_statistics.py`，参数统一位于 `settings.py`，当前算法版本 `bt-dual-scope-v3-<parameters SHA摘要前12位>`。下面区分当前产品规则和历史 V2 校准结果；不把匿名标识等同于真人，不声称代表全体玩家或保证人人等权。

## 一次采集、两个统计视图

形态视图只采用记录了双方实际形态的新回答；人物视图映射胜负双方，并混合窗口内仍合格的旧人物回答。每种视图独立执行最新无序对去重、K/L 权重、拟合、资格判断与综合百分位，人物分数不由形态分数相加或平均得到。旧票不猜形态，未出场的同人形态不增加胜负。

派题先按人物分配机会再选形态，所有形态共享人物曝光上限。当前支持在形态视图逐形态计数，人物视图采用同一参与标识的所属人物并集，并保留历史未指定形态的支持；同人本命不重复计数。快照唯一键与趋势序列包含 `scope`，默认界面为“干员分开”，API 未传 scope 仍默认 person 以兼容旧客户端。

本次新增的合成检查使用不同形态数量验证人物对去重和贡献封顶，不据此声称形态池的区间覆盖已校准。详细取舍与旧数据处理见[双口径方案](PREFERENCES_IDENTITY_PROPOSAL.md)。

## 随机好感：完整窗口、去重和双上限

84 天与 28 天分别从完整 `(cutoff-window, cutoff]` 窗口计算。仅采用风险状态合格、双方仍在当前名录的明确比较。同一匿名标识与当前视图的无序对象对，只保留窗口内最新有效明确判断；后来跳过不会覆盖已有明确判断，左右互换仍是一对。原始任务、答案、风险与审计不删除。支持、皮肤、形态及练习不转成随机票。

去重后，`n_u` 是标识 u 的比较数，`d_ui` 是涉及对象 i 的比较数（人物视图为人物、形态视图为具体形态或 NPC 单例）：

```text
w(u,i,j) = min(1, K/n_u, L/d_ui, L/d_uj)
K = 50，L = 1
```

对每个 u，逐条 `w ≤ K/n_u`，故全部比较权重之和不超过 K；涉及 i 的每条 `w ≤ L/d_ui`，故人物直接比较贡献之和不超过 L。只答一题权重为 1，不领取 50；按周恢复题额不重置窗口权重。多答题可以重新分配、稀释此前权重。上限约束输入证据量，不能保证最终分数变化的上限。

同一权重同时进入 BT 胜场计数与比较边计数。`P(i胜j)=a_i/(a_i+a_j)`；对每人物加入与固定强度锚点各 0.5 份的对称胜负先验，以 MM 更新并优化整体尺度，最多 500 次、log 强度差容差 `1e-6`。展示分是相对此快照实际有比较者组成的固定参照池的平均预测胜率（含自对位概率 0.5）；搜索不重新拟合。

无比较新人物不进入模型参照池、不补 50。实际观察网络有多个分量时，不将它们靠先验连接，相关分数/区间不公开为统一可比分数。有比较但未达门槛者可显示模型分项，不给名次。

按匿名标识成组 bootstrap 200 次，返回 2.5%–97.5% 百分位区间；抽中同一组多次时每份副本保留已算权重，不再次按原身份去重或封顶。ESS 使用人物上各标识总权重的 Kish 量 `(Σw)^2/Σw²`，表示集中程度，不是独立真人数量。

| 可排名条件（同时满足） | 默认 |
| --- | --- |
| 去重明确比较数 | ≥30 |
| 加权证据量 | ≥20 |
| 不同匿名标识数 / 聚类 ESS | 均 ≥30 |
| 不同对手 | ≥15 |
| 区间宽度 | ≤30 分 |
| 上限敏感性位移 | ≤10 分 |
| 其他 | 网络连通、拟合与重采样收敛、非全胜/全败 |

原始判断数、去重数、加权量、标识数、ESS、对手、实际窗口分别保存。原始对位接口仍展示实际受理判断，不伪装成模型概率。

## 综合榜：近期随机好感 + 当前支持

```text
C_i = 0.70 × P_E(R_i84) + 0.30 × P_E(S_i,current)
P_E(x) = 100 × (严格小于 x 的人数 + (与 x 同值人数 - 1)/2) / (|E|-1)
```

E 为随机结果达到上述资格且具有同截止点支持计数的人物，至少 3 人；当前有效支持名单的独立匿名标识至少 30 个。当前支持同一人最多一份；本命不另加分，不按支持名单长度放大单推用户权重。两项时间口径不同，不能称统一 84 天民意。

同值同分，综合指数相同用竞争排名。全体实测零支持时，同值百分位为 50 是中秩定义；仅在资格和支持参与门槛满足时成立，不可用来填补缺失随机分。新 NPC、网络不足或低样本保留有效分项，综合分与名次为 null，不降级为纯厨力榜。

快照保存完整 E、参照摘要、公式、参数、候选、算法、素材及修订。搜索和范围显示只过滤行，不改变 E。70/30 是突出随机好感的产品定义；同时计算 60/40、70/30、80/20，名次跨度达到 `max(3,ceil(|E|×10%))` 时标记权重敏感及范围。

趋势只在同统计视图/榜种/窗口/对象、名录、算法参数、素材、参照摘要与修订下连线；跨口径显示节点，不虚构升降。旧算法快照保留；完整历史足够时，以新算法另建序列。7/28 天基线缺失返回 null。

## 历史 V2 人物池模拟（seed 20260923）

该结果属于旧人物池，不能当作 V3 双榜校准。冻结报告为 [simulation-v2.json](../data/preferences/simulation-v2.json)。600 个合成参与标识、32 个已知强度人物、12,000 条判断，84 天内去重 11,791 条；200 次聚类重采样，不写数据库。

| 检查 | 结果 |
| --- | --- |
| 已知两两序关系恢复 | 96.77% |
| 平均分数绝对误差 | 1.689 / 100 |
| 单次人物区间覆盖 | 28/32（87.5%） |
| 基础加权证据量 | 5,118.8333 |
| 单题标识权重 / 左右互换最大差 | 1 / 0 |
| 同一高活跃标识增加 480 条 | 目标分变化约 +0.217 |
| 跨周重复同人物增加 1,440 条 | 目标分变化约 +0.236，人物贡献仍 ≤1 |
| 10 个单题新标识 | 目标分变化约 +1.767 |
| 120 个集中偏向的新标识 | 目标分变化约 +20.504 |
| 追加 5,000 条跳过 | 模型分变化 0 |

宽池另用 581 人物、同标识 1,440 条（去重 1,433）验证全局预算：K=25/50/100 分别得到总权重 25/50/100，L=1 始终成立。小池中 L 可能先绑定，不应把总权重没达到 K 误当失效。28/84 天分别去重与赋权、跨周、冷启动、跳过、组复制、旧记录保留均有回归。

K/L/先验网格均收敛。L=2 在本次已知强度上恢复略高，但允许同一人物更多直接贡献；采用 L=1 是保留产品约束的取舍，不能声称参数经证明最优。门槛联合检查证据与集中程度，取代首版仅以 60 原始条数衡量；真实流量仍需复评。

相对默认并列百分位 70/30，60/40 最大移动 4 名、80/20 移动 3 名；原始 min-max 的 70/30 移动 11 名、60/40 移动 19 名；对数支持再 min-max 的 70/30 移动 3 名。5 行被标记权重敏感。选择百分位保留同值、便于解释和复验，不是综合指标公平性证明。

单次区间覆盖 87.5% 没有验证总体 95% 覆盖；区间只描述已观察样本与模型下的重采样不确定性。新身份集中参与仍是明确弱点，贡献上限不是反女巫证明。公众自选参与、冷启动网络、真实容量和长期稳定性须在至少两周真实试运行中再验证，不能从这份报告推断人口代表性。

方法背景为 [Turner / Firth 的 Bradley–Terry 论文](https://www.jstatsoft.org/article/view/v048i09)和 [OECD/JRC 综合指标手册](https://www.oecd.org/en/publications/handbook-on-constructing-composite-indicators-methodology-and-user-guide_9789264043466-en.html)。双上限、门槛及 70/30 是本站规则，不是这些文献中的现成保证。

补样策略的 uniform-only 对照保留原窗口已算权重，作为诊断字段公开；当前排名门槛约束的是上限变化与区间宽度，未将 uniform-only 差值额外设为资格条件。
