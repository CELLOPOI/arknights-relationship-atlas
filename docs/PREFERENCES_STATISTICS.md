# 喜好统计口径与校准

实现为 `preference_algorithm.py`、`preference_solver.py`、`preference_statistics.py`，参数统一位于 `settings.py`，当前算法版本 `bt-dual-scope-v4-<parameters SHA摘要前12位>`。下面区分当前产品规则和历史校准结果；不把匿名标识等同于真人，不声称代表全体玩家或保证人人等权。

## 一次采集、两个统计视图

形态视图只采用记录了双方实际形态的新回答；人物视图映射胜负双方，并混合窗口内仍合格的旧人物回答。每种视图独立执行最新无序对去重、K/L 权重、拟合、资格判断与综合百分位，人物分数不由形态分数相加或平均得到。旧票不猜形态，未出场的同人形态不增加胜负。

派题先按人物分配机会再选形态，所有形态共享人物曝光上限。当前支持在形态视图逐形态计数，人物视图采用同一参与标识的所属人物并集，并保留历史未指定形态的支持；同人本命不重复计数。快照唯一键与趋势序列包含 `scope`，默认界面为“干员分开”，API 未传 scope 仍默认 person 以兼容旧客户端。

本次新增的合成检查使用不同形态数量验证人物对去重和贡献封顶，不据此声称形态池的区间覆盖已校准。详细取舍与旧数据处理见[双口径方案](PREFERENCES_IDENTITY_PROPOSAL.md)。

## 随机好感：完整窗口、去重和双上限

84 天与 28 天分别从完整 `(cutoff-window, cutoff]` 窗口计算。仅采用风险状态合格、双方仍在当前名录的明确比较。同一匿名标识与当前视图的无序对象对，只保留窗口内最新有效明确判断；后来跳过不会覆盖已有明确判断，左右互换仍是一对。原始任务、答案、风险与审计不删除。支持、皮肤、形态及练习不转成随机票。

去重后，`n_u` 是标识 u 的比较数，`d_ui` 是涉及对象 i 的比较数（人物视图为人物、形态视图为具体形态或 NPC 单例）：

```text
w(u,i,j) = min(1, K/n_u, L/d_ui, L/d_uj)
K = 50，L = 1
```

对每个 u，逐条 `w ≤ K/n_u`，故全部比较权重之和不超过 K；涉及 i 的每条 `w ≤ L/d_ui`，故人物直接比较贡献之和不超过 L。只答一题权重为 1，不领取 50；按周恢复题额不重置窗口权重。多答题可以重新分配、稀释此前权重。上限约束输入证据量，不能保证最终分数变化的上限。

同一权重同时进入 BT 胜场计数与比较边计数。`P(i胜j)=a_i/(a_i+a_j)`；对每人物加入与固定强度锚点各 0.5 份的对称胜负先验，以 MM 更新并优化整体尺度。稀疏比较边预编译为 NumPy 数组，最多迭代 5,000 次；log 强度变化与按对象证据量归一化的似然梯度残差均低于 `1e-6` 才算完成。重采样和对照拟合以基础解为初值，保持同一目标与停止条件。展示分是相对此快照实际有比较者组成的固定参照池的平均预测胜率（含自对位概率 0.5）；搜索不重新拟合。

无比较新人物不进入模型参照池、不补 50。实际观察网络有多个分量时，不将它们靠先验连接，相关分数/区间不公开为统一可比分数。有比较但未达门槛者可显示模型分项，不给名次。

按匿名标识成组 bootstrap 1,000 次，返回 2.5%–97.5% 百分位区间；抽中同一组多次时每份副本保留已算权重，不再次按原身份去重或封顶。抽样种子绑定有效对位、权重、参照池及模型版本，不绑定窗口标签或生成时间；相同有效输入得到相同分数、区间及状态。ESS 使用人物上各标识总权重的 Kish 量 `(Σw)^2/Σw²`，表示集中程度，不是独立真人数量。

基础拟合、全部重采样与两组上限对照都完成后才给出区间与名次。任何必需拟合达到迭代上限仍未完成，区间和名次均为空；不能混入失败结果，也不能只用成功子集缩窄区间。基础拟合本身失败时分数也为空。快照分别记录迭代次数、残差及重采样成功/失败数，计算问题不再与意见分歧共用状态。

可排名对象另给出重采样名次范围，固定比较本次合格集合，按同分竞争排名求 2.5%–97.5% 百分位并向外取整。页面显示“可能第 X–Y 位”，不把相邻点估计名次解释成稳定高下；该范围不包含本次尚未合格的对象，也不是全榜同时覆盖保证。

| 可排名条件（同时满足） | 默认 |
| --- | --- |
| 去重明确比较数 | ≥30 |
| 加权证据量 | ≥20 |
| 不同匿名标识数 / 聚类 ESS | 均 ≥30 |
| 不同对手 | ≥15 |
| 区间宽度 | ≤30 分 |
| 上限敏感性位移 | ≤10 分 |
| 其他 | 网络连通、拟合与重采样收敛、非全胜/全败 |

原始判断数、去重数、加权量、标识数、ESS、对手、实际窗口分别保存。原始对位接口仍展示实际受理判断，不伪装成模型概率。

页面将数量未达门槛、分数区间过宽、上限敏感和计算失败分别简写为“还需更多投票”“排名未稳”“计分影响较大”“统计未完成”。资格门槛、K/L、先验及综合权重没有降低。V4 只新增带新算法版本的快照；原始任务、支持、本命、外观选择、额度及旧快照均保留，不需要数据库迁移。

## 综合榜：近期随机好感 + 当前支持

```text
C_i = 0.70 × P_E(R_i84) + 0.30 × P_E(S_i,current)
P_E(x) = 100 × (严格小于 x 的人数 + (与 x 同值人数 - 1)/2) / (|E|-1)
```

E 为随机结果达到上述资格且具有同截止点支持计数的人物，至少 3 人；当前有效支持名单的独立匿名标识至少 30 个。当前支持同一人最多一份；本命不另加分，不按支持名单长度放大单推用户权重。两项时间口径不同，不能称统一 84 天民意。

同值同分，综合指数相同用竞争排名。全体实测零支持时，同值百分位为 50 是中秩定义；仅在资格和支持参与门槛满足时成立，不可用来填补缺失随机分。新 NPC、网络不足或低样本保留有效分项，综合分与名次为 null，不降级为纯厨力榜。

快照保存完整 E、参照摘要、公式、参数、候选、算法、素材及修订。搜索和范围显示只过滤行，不改变 E。70/30 是突出随机好感的产品定义；同时计算 60/40、70/30、80/20，名次跨度达到 `max(3,ceil(|E|×10%))` 时标记权重敏感及范围。

趋势只在同统计视图/榜种/窗口/对象、名录、算法参数、素材、参照摘要与修订下连线；跨口径显示节点，不虚构升降。旧算法快照保留；完整历史足够时，以新算法另建序列。7/28 天基线缺失返回 null。

## 参与额度与全池样本下限（2026-09-25）

正式参与额度为每周 300 道、滚动 28 天 1,200 道、同一人物 28 天最多展示 6 次。581 人物目录（397 干员、184 NPC）对应 624 个独立比较对象（440 干员形态、184 NPC）。1,200 道需要 2,400 次人物展示，平均每人物约 4.13 次；旧单人物 3 次上限只能支持最多 871 道，因此配套调整为 6 次。跳过及过期仍占派题额度，84 天同对限制、K/L、休息提示、风控及入榜门槛保持原规则。

全池达到最基本数量条件的理论下限如下，**不表示达到这些数字就能全员排名**：每条比较覆盖两个对象，每个对象需要 30 条去重比较和 20 份加权证据，每个匿名标识在完整窗口最多贡献 K=50。

| 必要条件 | 581 人物 | 624 形态/NPC 对象 |
| --- | ---: | ---: |
| 去重明确比较数至少 | 8,715 | 9,360 |
| 全池比较权重之和至少 | 5,810 | 6,240 |
| 每标识满额贡献时的标识数至少 | 117 | 125 |

以上是总量必要条件，仍须逐对象满足 30 标识/ESS、15 对手、区间宽度、连通及稳定性等条件，综合榜另需足够支持名单。多形态人物的展示机会还会被形态分摊。提高答题额度主要补覆盖与对位，不增大单标识统计贡献；更多独立参与和持续覆盖仍是冷启动所需。未据此放宽 K/L 或入榜门槛。

三个额度直接由 `settings.py` 提供，更新 API 后生效，不重置已有任务或额度使用数，无需数据迁移。既有统计快照保留；个人练习及个人榜始终不进入公共统计。

## V4 宽池数值检查（2026-09-26）

使用 624 个合成对象、321 个标识、18,036 条明确判断，按标识分别生成 10/30/75/212 条（人数为 96/96/96/33）；同标识不重复对象对，每对象最多展示 6 次。真实 log 强度等距分布于 `[-2.8,2.8]`，对位均匀抽取，胜负按 BT 概率产生。种子为 20260926、20260927、20260928，不读取业务票据。

三组各 1,000 次重采样全部完成，最长分别为 1,060、1,003、921 次迭代；其中 367、198、175 次超过旧上限 500。每组实际调用完整随机统计约 50–62 秒，仅为本机合成计时。另将首组增加到 2,000 次，计算约 119 秒，全部完成；相对 1,000 次的分数区间端点最大差为 1.291 分，95% 的端点差不超过 0.667 分，没有资格状态变化，名次范围端点最大差 11 名。默认选 1,000 次以平衡重算耗时与蒙特卡洛误差，名次范围仍是近似值。

三组单次对象区间覆盖分别约 92.8%、92.8%、94.6%，不足以验证总体 95% 覆盖，也未模拟真实自选参与偏差。此次验证支持修复迭代提前终止和同输入重算抖动，不证明样本已能精确区分相邻名次。回归测试另覆盖旧解数值一致、弱连接网络、组复制权重、失败结果隔离、相同输入跨窗口一致及原始记录/旧快照保留。

## 小时汇总与性能优化（2026-09-26）

保持 V4、1,000 次重采样、收敛阈值与入榜条件。拟合结束的目标值诊断由短向量点积改为逐项乘积求和，避免唤醒 BLAS 多线程；容器额外默认设置 `OPENBLAS_NUM_THREADS=1`、`OMP_NUM_THREADS=1`、`MKL_NUM_THREADS=1`。目标值不参与迭代或停止判断，仅可能有浮点求和末位差异。线程行为依据 [NumPy 全局状态说明](https://numpy.org/doc/stable/reference/global_state.html)与 [OpenBLAS 使用说明](https://github.com/OpenMathLib/OpenBLAS/blob/develop/USAGE.md)。

每轮取出的全部原始记录都严格落在近 28 天内时，同一统计视图的 84/28 天输入完全一致，只计算一次并深拷贝结果，分别保留窗口起点和实际天数。判定包含跳过与不熟悉记录；恰在 28 天边界或更早的任一记录都会恢复独立计算。人物、形态仍分别拟合；不做跨轮持久缓存，不凭记录数量猜测输入相同。数据积累超过 28 天后，这项窗口复用收益可能消失。

用上述 seed 20260926 的 624 对象、321 标识、18,036 判断做单视图双窗口对照，全部记录设在同一截止点前两天，每次拟合保留 1,000 次重采样。旧代码使用 4 个 BLAS 线程，新代码使用 1 个线程并复用相同窗口：

| 本机合成对照 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 实际耗时 | 89.925 秒 | 43.763 秒 |
| 进程 CPU 时间 | 336.584 秒 | 41.232 秒 |
| 平均占用核数（CPU 时间 / 实际耗时） | 3.74 | 0.94 |

两窗口的完整结果除目标值诊断约 `2e-12` 的浮点差异外一致，包含分数、区间、资格、名次、样本量与收敛诊断。本机单次计时约缩短 51%，CPU 时间约减少 88%；不含数据库取数、两种视图的整批发布或网页请求，不能等同线上耗时或容量保证。

汇总调度改为每 60 分钟，减少每日重复计算和新增快照量。历史趋势先按日期、口径元数据筛选，再读取最多 180 份完整快照，避免先反序列化全部历史榜单。回归覆盖窗口边界、跳过、不熟悉、深拷贝隔离、旧记录保留、密集历史选择和两小时新鲜度；无需数据库迁移，既有快照保留。

| 平均分数绝对误差 | 1.689 / 100 |
| 单次人物区间覆盖 | 28/32（87.5%） |
| 基础加权证据量 | 5,118.8333 |
| 单题标识权重 / 左右互换最大差 | 1 / 0 |

| 120 个集中偏向的新标识 | 目标分变化约 +20.504 |

宽池另用 581 人物、同标识 1,440 条（去重 1,433）验证全局预算：K=25/50/100 分别得到总权重 25/50/100，L=1 始终成立。小池中 L 可能先绑定，不应把总权重没达到 K 误当失效。28/84 天分别去重与赋权、跨周、冷启动、跳过、组复制、旧记录保留均有回归。

K/L/先验网格均收敛。L=2 在本次已知强度上恢复略高，但允许同一人物更多直接贡献；采用 L=1 是保留产品约束的取舍，不能声称参数经证明最优。门槛联合检查证据与集中程度，取代首版仅以 60 原始条数衡量；真实流量仍需复评。

相对默认并列百分位 70/30，60/40 最大移动 4 名、80/20 移动 3 名；原始 min-max 的 70/30 移动 11 名、60/40 移动 19 名；对数支持再 min-max 的 70/30 移动 3 名。5 行被标记权重敏感。选择百分位保留同值、便于解释和复验，不是综合指标公平性证明。

单次区间覆盖 87.5% 没有验证总体 95% 覆盖；区间只描述已观察样本与模型下的重采样不确定性。新身份集中参与仍是明确弱点，贡献上限不是反女巫证明。公众自选参与、冷启动网络、真实容量和长期稳定性须在至少两周真实试运行中再验证，不能从这份报告推断人口代表性。

方法背景为 [Turner / Firth 的 Bradley–Terry 论文](https://www.jstatsoft.org/article/view/v048i09)和 [OECD/JRC 综合指标手册](https://www.oecd.org/en/publications/handbook-on-constructing-composite-indicators-methodology-and-user-guide_9789264043466-en.html)。双上限、门槛及 70/30 是本站规则，不是这些文献中的现成保证。

补样策略的 uniform-only 对照保留原窗口已算权重，作为诊断字段公开；当前排名门槛约束的是上限变化与区间宽度，未将 uniform-only 差值额外设为资格条件。
