# 高关联人物的分组浏览

2026-09-20 实施。凯尔希等高关联人物原先展开大分组时，会复用小分组的旧中心坐标；组框重新排布后，缓存中的成员坐标又没有同步移动。两种问题叠加，造成头像与主角、其他分组重叠，以及空组框。此次同时修正布局状态和日常查看流程。

同日后续按用户选择加入轻盈漂浮、错落布局和按需显线；当前动效及显示开关见 [GRAPH_MOTION.md](GRAPH_MOTION.md)。本文保留分页、归属、历史恢复与布局边界的说明。

关联超过36人的人物默认显示分组总览。点击一个分组后，画布保留主角，只展示当前组的一页人物，顶部显示组名、当前范围、翻页按钮与“本组名录”；点“全部分组”恢复进入前的总览、拖动位置和视角。侧栏点某个国家或阵营时，直接查看该阵营，不会连带显示“其他阵营”里的所有成员。关联较少的人物保留原来的完整关系图。

每页容量依据画布宽高计算，桌面1440×960显示18人，手机390×844与横屏844×390显示4人。姓名保持可读，超长姓名在节点上省略，完整姓名仍可在悬停说明、键盘标签和名录中读取。本组名录包含该组全部人物，查找后点击“定位”会跳到目标所在页；原有“关系名录”仍能检索主角的全部关系。点击人物继续探索，点击连线或名录中的详情查看原文；悬停或键盘聚焦人物会突出其相关连线。

全部展开继续可用，作为完整关系总览。区域半径改为根据成员实际外沿和标签留白计算，分组与主角、分组之间检查间距。自动生成的成员坐标随组框一起重新布局，用户拖动单独记录，不能把上次生成的坐标误当手动固定位置。同一数据下，展开顺序、收起再展开均不得出现空框或脱离所属区域的自动节点。

浏览历史保存当前组、页、坐标、手动拖动标记及进入前的总览。版式发生变化时重新计算分页，保留此前页首所在的阅读位置；返回总览时按新画布尺寸适配。布局版本标记用于拒绝旧版重叠坐标，不影响人物链接。刷新时 Vue 会异步补入人物动作，造成页头高度变化；若最终画布尺寸与历史一致，尺寸观察器保留用户缩放，避免再次执行自动适配。

所有改动位于前端图谱模块与既有界面样式，人物、关系方向和证据未修改。布局距离仍不代表关系强弱。分组状态保存在当前页面历史中，没有写入账号；分享人物 URL 会打开该人物的默认视图，跨设备布局同步不在本次范围。
