# 分区、粒子与关系图的职责边界

Status: implemented
Date: 2026-09-17

2026-09-18 更新：下文记录静态原型的初始选择。公开站点升级已引入 Vue 3、Django 和 PostgreSQL，现行方案见 [当前实现](../../../../docs/CURRENT_IMPLEMENTATION.md)。`site.js`、`app.js`、`particles.js` 的职责分别承接到 `frontend/src/atlas/portal.js`、`graph.js`、`particles.js`；静态交付及无需后端的前提已被替代，本文的图形、历史恢复、粒子生命周期与证据语义约束继续适用。

2026-09-18 阵营调整：用户明确指定“联动”父级及四支小队目录共用彩虹小队粒子效果，这是下述“缺徽记不借用其他阵营标志”约束的明确例外。四支小队的正式阵营 ID 不合并，`group=collaboration` 仅记录导航层级，并兼容原小队链接。用户确认的六位未归属人物转入罗德岛，生成器补充表与数据库审计迁移同步，原始核查关系及证据不变。验证见 [阵营调整记录](../../../../docs/FACTION_UPDATE.md)。

用户要求以现有官网参考的审美增加首页、干员阵营分区与关系图次级页，并明确保留人物的完整跨阵营关系。参考工程必须只读，原始人物与证据数据不得改变。

沿用原生ES模块：`site.js` 管理 `#home / #factions / #graph` 和粒子展示；`app.js` 管理图谱、人物选择、证据面板与历史快照；`particles.js` 迁移已理解的独立实验模块。`faction` 为初始阵营范围，`person` 保留原来的稳定ID语义。只在阵营总览裁选人物及内部边；进入人物页始终从全量邻接表取关系，不沿用阵营过滤。

保留完整原站webpack可以更接近原站内部实现，但会引入与本项目无关的页面、运行时和模块ID。引入前端框架或路由库可减少手写状态代码，但原型只需三种页面状态，故当时继续采用平台API。初始分区使用方向性clip-path转场，首页与干员区后按下述滚动修复替换；图谱缩放不受整页滚轮监听影响。快速点击通过取消旧动画和请求编号收敛到最新状态，不延迟业务导航。

2026-09-23 双向滚动修复：旧处理排除了粒子区、目录和控件，导致手机大部分区域不能切屏、桌面目录到顶仍不能返回；游戏独立文档也没有向上返回的手势。`section-scroll.ts` 统一识别纵向触摸与累计滚轮输入，控件保持点击，编辑字段和打开的弹窗不切屏。可滚动内容优先使用原生滚动；从内容内部开始的同一次手势只滚内容，到边界后下一次同向手势才切屏。横向、多指和取消手势不翻页。滚轮已消费状态跨应用保留，防止同串惯性从阵营继续跳入游戏。此处替代下文 2026-09-21 对粒子区拖动的排除：横向保留粒子交互，纵向达到阈值后切换分区。

首页、阵营的旧新内容同时保留 600ms 纵向过渡，离开的内容临时 inert，动画结束再隐藏；共享画布只调整一次布局，以变换衔接。`main.ts` 在同一文档内切换独立 Vue 入口，先卸载旧应用再挂载新应用；浏览器 View Transition 保存旧画面，避免图谱与游戏监听并存，也避免整页跳转的空白。继续整页跳转更简单，但无法衔接两侧画面和滚轮手势；同时常驻两个应用会增加图形资源和全局事件冲突，因此采用独立挂载加浏览器快照。无 View Transition 时使用短距离进入过渡，减少动态时直接切换。滚动返回保留资料范围和联动目录，游戏进度继续从本地保存恢复；图谱缩放、弹层内部滚动不加入分区导航。

验证入口为 `scripts/verify-section-scroll.mjs`，使用只读 API 夹具检查上下切屏、原生目录滚动、惯性、浏览历史、游戏保存、对话框、减少动态与动画降级。Chromium 以 CDP 触摸验证原生手势，WebKit 触摸仅覆盖合成 TouchEvent 分派，不能代替 iPhone 真机验收。浏览器与构建结果保存在忽略的 `.runtime/verification/section-scroll/`，不以桌面无头运行推断真机帧率。

每个图谱快照包含页面、scopeFaction、focus、展开状态、坐标和相机。缓存键同时包含阵营和人物，避免同一人物在不同入口共享错误的布局。显示／隐藏页面引发的ResizeObserver回调不能覆盖恢复的相机；仅可见画布的实际尺寸变化触发重新适配。

2026-09-20 高关联交互更新：普通分组点击进入保留主角的分页浏览，全部展开保留为显式动作。大组继续在总览原位直接展开虽然操作步骤少，但会同时显示数十至上百个人物及连线，无法在有限画布保持可读，因此默认采用逐组查看。自动坐标与手动拖动标记分别维护，组框的真实边界参与碰撞计算；历史中额外保存当前分组、页与进入前的总览。旧布局版本坐标失效后重建，用户的复核资料不受影响。Vue 异步补入页头导致的初次尺寸变化，须与保存的最终视口比较，不能覆盖恢复的缩放。实施、验证和阅读状态边界见 [关系分组交互](../../../../docs/RELATION_GROUPS.md)。

粒子离开分区或页面不可见时停止 RAF；减弱动态时静态采样，不能靠CSS隐藏动画继续计算。无WebGL时使用Canvas 2D。缺少经核实徽记的分组用无标识点云，不借用其他阵营的标志。图形上下文丢失可重载恢复，关系图导航保持可用。

2026-09-21 粒子调整：按用户要求移除手动散开、暂停控制及状态；悬停／触摸扰动继续保留。Canvas 仅绘图，外层 `.particle-stage` 接收指针，使右键保留浏览器页面菜单；只对主按钮或触摸按下施加涟漪，粒子区触摸拖动不作为分区滑动。实际右键回归检查命中普通 DIV 且默认菜单未被拦截，同时覆盖悬停、触摸释放与监听清理。阵营页整面透明内容层此前截走画布事件，现只让目录与实际控件接收指针，空白和标题透传；同步播放状态也不再无条件清除悬停。用户随后明确仍需从边缘飞入，替代了曾采用的原位显影打印：粒子初始位置位于画布边缘之外。后续按用户要求拆为九类结构路径，由 `emblem-motion.js` 按徽记及归一化目标点位置规划：三角边框沿斜边、塔身沿纵轴，角枝从上方分流，翼形两侧掠入，放射形沿尖刺收束，圆环沿切线绕入，斜纹平行穿入，对称主体弯曲合拢，蛇杖交织，联动倒三角与数字分层组装。路径与矩形视口求交确定屏外起点，切图时预计算三次曲线控制点；逐帧仅求曲线和弹簧追踪，不逐点判断徽记类型。起点、出发时间、速度及小幅路径偏移保留随机性。真实位置沿路径连续前进，约 1,620 ms 汇成图案，不使用整圈向同一中心收缩。激光表现改为跟随实际速度的短尾迹，长度不超过归一化坐标 0.07，不连接成贯穿画面的长线。桌面同时最多 96 根引线，窄屏、低高度横屏及 Canvas 最多 48 根，落定后清空引线并恢复静态样式缓冲。数据同步时相同徽记不重复入场；从首页或关系图进入干员页则显式重播，并先更新画布尺寸，修复首页与干员页共用缓存导致跳过播放的问题。重播不等待页面转场结束。系统减少动态时直接显示完整点阵且无引线，隐藏期间不推进飞行时间。用户随后提供源站稀疏点阵截图。初次直接减量约七成并统一网格化使可读性下降，已改为轮廓与内部填充分配独立预算：桌面粒子数回调为原先一半，最多 38% 优先保留边界、文字与细线，其余在内部均匀分布。每格选择真实前景像素，避免格心落入文字间隙或空洞；提高单点亮度，轮廓粒子进一步加强可见度。飞入路径与悬停交互继续保留。粒子回归覆盖现用徽记与桌面／手机视口。密度与浏览器回归入口见 [当前实现](../../../../docs/CURRENT_IMPLEMENTATION.md)。

2026-09-21 手机整页重载排查：用户确认现象包含整页重新加载或闪白。源码与隔离浏览器观察均未发现粒子落定后定时重播；实际断开开发页面的 Vite 热更新连接后，客户端在连接恢复时调用整页重载，文档时间起点与粒子帧计数重新开始。素材准备脚本重跑未复现该重载，不据此修改素材流程。手机持续体验改用单独构建目录的生产预览，避免开发源码变更、热更新重连及日常构建干扰；HTML 在应用脚本与外部样式前提供深色背景。启动方式见 [开发文档](../../../../docs/DEVELOPMENT.md)。`verify-mobile-preview.mjs` 在 Chromium 与 WebKit 的手机视口中验证延迟资源时无白底、无热更新连接、停留与断网恢复及横竖屏变化不重载／重播，显式切换阵营仍播放入场。这些结果确认开发服务的可复现触发链路，尚未获得用户真机日志，不能排除其他手机端重载原因。

沿用现有弹簧模拟与 WebGL／Canvas 渲染，以预计算相位和限制粒子数控制逐帧成本。`scripts/verify-particles.mjs` 检查现用徽记的屏外起点、途中位移、有限坐标、最终归位、重复同步不重播、九类路径覆盖，另检查首页进入后的即时播放、尾迹消退、WebGL 错误、悬停恢复、快速切换、手机横竖屏、减少动态和 Canvas 回退。短时桌面采样不能用于承诺真实手机帧率。

2026-09-20 泡泡动态扩展：用户选择轻盈漂浮、组内错落聚拢并保留分页。`graph-motion.js` 单独管理显示坐标，布局与拖动锚点仍由 `graph.js` 持有；SVG 头像、实际关系曲线和短暂展开粒子在同一帧绘制，浮动不进入历史。真实力导向模拟能产生更多碰撞变化，但会持续改变阅读位置、拖动结果及恢复坐标；单纯 CSS 漂浮容易使头像和连线端点脱节，因此本次使用有界显示偏移与可打断的过渡。悬停固定头像，仅在入场结束后生效，避免经过指针的节点停在途中。默认仅更新聚合或当前突出关系的曲线，大总览限制更新频率；全部显线是显式选项。离开图谱、隐藏页面、手动暂停和系统减少动态时停止动画循环。实现与实际验证范围见 [泡泡动态与连线](../../../../docs/GRAPH_MOTION.md)，不将短时桌面样本解释为真实手机性能保证。

详情使用原生dialog并补充首尾Tab循环；仅首次打开播放整体入场动画，内部切换保留稳定顶栏和独立滚动正文；关闭动画结束恢复触发点。证据请求返回前须核对当前panelMode，旧请求不能重开已关闭或已切换的面板。

低高度横屏减少相机适配留白，以横向点阵显示单阵营，人物视图默认聚合；不删减人物或关系。分组字号有最小可见值时，标签行距也必须按相机比例调整，避免字仍可见但行相互重叠。此布局判断只影响初始展示，拖动与历史坐标仍按原有快照维护。

收益是维持现有静态部署与资料契约，同时获得独立入口和粒子展示；代价是手动维护路由、焦点与图形生命周期。增加更多具有独立数据加载和嵌套路由的正式分区时再评估路由库，不为待定位置提前扩展架构。

复验入口见[开发指南](../../../../docs/DEVELOPMENT.md)和[工具索引](../../../../scripts/README.md)。浏览器模拟不代表真实手机 GPU 性能，不承诺帧率或性能提升比例。
