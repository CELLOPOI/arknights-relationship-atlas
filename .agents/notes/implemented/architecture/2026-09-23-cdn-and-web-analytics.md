# 代理入口与访问统计

Status: implemented
Date: 2026-09-23

网站接入 CDN 后，Caddy 的直连地址会变成代理节点。继续把 `{remote_host}` 传给 Django，会使多个访客共用反馈、后台登录及喜好接口的 IP 限流标识。访问统计也应能随应用发布保留，不能依赖临时修改容器里的网页。

## 决定与边界

Caddy 通过运行变量 `CADDY_TRUSTED_PROXY_CIDRS` 显式接收可信入口代理网段，默认留空。只对可信连接从右向左解析 `X-Forwarded-For`，将确定的单个 `{client_ip}` 传给 API，并继续覆写协议和删除 `Forwarded`。Django 仅信任固定的 Caddy 地址，原有限流与数据库逻辑不变。直连请求不能通过伪造请求头获得信任。

启用 Cloudflare 橙云时可以使用平台自动安装 Web Analytics；灰云和手动安装优先通过 API 的运行环境提供站点标识，见下述运行时接入。专用构建继续兼容原有生产构建参数。实际标识留在部署配置，公共镜像构建保持空值；同一页面已有 beacon 时不重复安装。开启代理、后台统计设置及生产验收属于独立的部署步骤，源码实现不代表线上已启用。

CDN 来源网段由部署者根据提供商官方列表维护；不动态下载后直接加入信任，不使用全部公网或全部私网。TLS 继续由 Caddy 管理，Cloudflare 回源使用 Full (strict)。运行配置和证书持久卷跨版本保留。

## 备选与代价

直接沿用连接地址最简单，适用于没有 CDN 的入口，因此保留为默认行为；代理入口需要额外的可信来源判断。无条件转发 `CF-Connecting-IP` 能减少配置，但公开源站可能收到访客伪造的同名头，不能用它替代来源验证。标准 Caddy 的静态代理列表无需额外插件，代价是提供商修改网段时要维护运行配置；代理种类或更新频率增加时再评估动态列表。

在源码中固定统计标识可以减少构建参数，但会把站点配置带给所有克隆与预览。构建注入保留了专用构建的手动安装能力，代价是干净 Git 归档构建须显式传参；橙云自动安装省去这项发布依赖，但灰云或平台禁用注入时需要切换到手动方式。

## 2026-09-24：公共镜像的运行时统计

公共 Registry 镜像不接收实例配置，关闭代理后也无法继续依赖平台自动注入。API 已通过 Compose 的 `env_file` 读取部署环境，因此新增只读 `/api/site-config/`，只返回经过格式检查的公开统计标识。开发模式、空值与非法值关闭统计，响应禁止缓存且不依赖数据库或会话；标识在浏览器中可见，不是管理凭据，不能借此接口公开其他设置。

生产前端独立获取配置，既不携带访客 cookie，也不阻塞应用挂载。配置失败或超时就跳过，成功后只加载固定来源的 Cloudflare module 脚本；加载前后均检查已有脚本，保留官方 SPA 跟踪而不按页面切换重复安装。原构建注入优先，开发前端不请求配置。

相比重新构建带实例标识的 Web 镜像，运行配置保持公共镜像可复用；相比容器启动时改写 HTML，不需要新的启动包装、挂载或 Compose 契约。代价是每次页面文档加载增加一次很小的同源请求，API 故障时无法启用统计，极短访问或配置尚未返回时的导航可能漏计。若需要独立于 API 的统计可用性，再评估服务端 HTML 注入。原有代理地址信任、TLS 和专用构建的约束继续有效。

## 验证

`scripts/verify_caddy_proxy.py` 在本机临时端口使用实际 Caddy 配置和回显上游。Caddy 2.11.4 下，直连、配置了其他来源网段、可信代理三种场景的 36 个断言通过，覆盖 `/api/ready/`、反馈、后台、IPv4/IPv6、伪造转发地址和协议、无转发地址以及禁止缓存响应头。验证没有写入业务数据，不代替真实 CDN 链路与监控平台验收。

手动统计的 Vite 构建已检查开发不注入、单次生产注入、空标识不注入、无效标识拒绝构建。使用真实站点标识的浏览器验证需要拦截上报，以免测试流量进入报表。操作约束集中维护在[开发指南](../../../../docs/DEVELOPMENT.md#cdn-与访客地址)。

运行时接入通过 `make check` 和独立 PostgreSQL 的 `make check-postgres`（174 项后端测试，PostgreSQL 无跳过）；新增接口测试覆盖字段白名单、匿名无数据库读取、开发禁用、错误配置及只读访问。`scripts/verify-web-analytics.mjs` 在本机生产预览中通过 11 个浏览器场景，覆盖启停、失败、5 秒超时、已有/迟到脚本与 SPA 历史切换。全部使用合成标识和模拟 beacon，不证明真实统计上报或平台报表入库。
