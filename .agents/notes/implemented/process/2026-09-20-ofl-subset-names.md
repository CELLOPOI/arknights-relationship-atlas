# 通过元数据改名维护现有 OFL 网页子集

Status: implemented
Date: 2026-09-20

现有思源黑体 2.004 Regular/Bold 与 Oswald 3.0 Medium 是参考站提供的网页子集，内嵌 OFL 1.1，相关版本保留名称 Source、Oswald。项目需要补齐许可条件，同时保持当前字形、排版和字符覆盖。仅补一份许可文本无法处理派生字体的保留名称；字体来源可公开访问也不能代替修改条件。

将三款字体分别改名为 Relationship Atlas CJK、Relationship Atlas Narrow，CSS 使用 AtlasCJK、AtlasNarrow。保留原作者版权，嵌入并随网站附完整 OFL；许可继续适用于字体本身。`scripts/prepare_ofl_fonts.py` 只接受三个已核对的输入 SHA-256，拒绝符号链接、已有输出和未知格式；全部文件处理成功后才写输出。保存后比较所有字体表，除 name 表及 head 校验和外必须逐字节一致，否则失败。此流程不允许用于 Novecento、Bender 等未纳入审查的字体。

改用完整上游字体可以简化子集来源链，但会改变下载大小、覆盖范围，字体版本或格式变化也可能影响排版。本次选择最小的元数据改动，保留既有子集；代价是需要保存对应来源、许可及固定输入哈希。未来增加字符或升级字体时应重新核对名称条件和浏览器显示，不能只更新哈希放过字形变化。上游免费或新版本许可也不能自动替换旧文件的条件。

固定依赖下重复生成的三个文件字节完全一致。独立复核确认原版权完整、名称记录已替换、其余表未变；字符覆盖仍为 896、902、101 个码点。未知输入、符号链接及已有输出的拒绝检查通过。新资源包完成打包、恢复与逐文件校验，`make check` 通过。Chromium 的 1440×900 和 390×844 首页/阵营页对照中，三款字体的采样 Canvas 像素、文字宽度和相关元素位置均一致，无横向溢出或脚本异常；未将这一结果推广为所有浏览器或整页动画像素完全相同。

来源和许可集中见 [字体维护](../../../../docs/ASSET_LICENSING.md#开放字体的维护)、[派生清单](../../../../assets/ofl-fonts.json)。本地验收不改变素材包整体的 unreviewed 状态，不证明 Bender Bold、游戏图片或远程托管已具备所需依据。
