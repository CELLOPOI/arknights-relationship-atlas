# 四种游戏模式与人物输入识别

Status: implemented
Date: 2026-09-21

用户反馈原六步探索缺少选路依据，普通玩家容易盲猜；本轮明确要求普通模式、原六步模式、自行输入名字的模式共存，输入模式也由系统给定起点与终点，支持真名、绰号和模糊输入。三种模式必须复用原来的左右人物立绘、灰色特写和精一／精二切换，只修改中间游戏内容，允许为适配微调位置。

新增双人判断后，用户明确修正流程：先判断两人是否直接认识；不直接认识时，再从人物池选择能同时连接两人的中间人。直接连线的类型和方向不影响游戏答案，原档案语义仍保留。每轮 10 题，5 对直接相连、5 对不直接相连但存在共同邻居；分池采样后打乱，同轮不重复同一人物对。完全随机抽两人的实现更短，但会大量出现不认识且不能经过一人接通的题，因此不采用。人物池不足时保留原轮，不用重复题或无解题填满配额。

间接题通常给 6 位候选，其中至多 2 位共同邻居，剩余为真正不满足两侧连线的干扰人物；只有一位共同邻居时放入一位，小人物池允许少于 6 个选项。第一步按用户后续要求改为点击“认识／不认识”即提交，不另设确认按钮。两个选项保留并锁定，所选答案用与暗色界面协调的浅绿／柔和红色反馈，附正确／错误文字；不直接认识时展开候选。选中中间人候选不显示关系，确认中间人后才给出有效路线与原文。任何有效候选都算正确，两步都对才算整题正确；第一步选错仍可尝试第二步。已确认答案不可修改，未完成第二步不能跳到下一题，刷新与切换保留两步状态。题单、候选、作答和形象单独校验恢复；旧的纯二选一题单重新生成，不影响三种连线进度。

用户试玩后进一步要求普通模式按一、二、三处空位区分难度，并指出点击候选直接显示两侧关系等于提前给出答案。因此普通模式采用两、四、六步最短路线，在第 1、3、5 步交错留空，保证每处都有可见的左右人物；旧的单空标准题和双空挑战题恢复时重新出题。候选最多六位，点击只选择，确认填入后才判定，不提前公开任何一侧关系。每空可主动使用一次排除提示，只排除一位错误候选并计数，原文在填对后或结算时查阅。任何满足两侧关系的候选都有效；不同空位候选互斥，避免前一处替代答案堵死后一处。选错记录次数并保留空位；揭晓后结束，重试清空作答与提示。

采用交错空位的代价是挑战题要求六步最短距离：当前基线与默认禁用下，仅干员范围有 4 组符合条件的无序端点对。当前不通过相邻空位隐去参照，也不以短题降低空位数；后续若要扩大挑战题库，应评估非最短的有效参考路线或人工精选题。该限制属于题库覆盖，不能用异格外观数量冒充更多关系路线。

六步探索保留原有全部合法邻居、六步额度、撤回、提示与结算。输入挑战复用同一个图与走步校验，但不公开邻居列表；姓名匹配只依赖输入文本与全体已收录人物，不按邻接关系筛选或排序，防止模糊搜索成为可走答案提示。唯一完整名称可以回车确认；部分名称、错字近似及多个完整匹配必须由玩家选择具体人物。识别身份后再检查范围、禁用、重复与连线；无效选择不消耗路线步数，中文输入法确认组词不会提交。

输入识别复用正式 API 的别名和统一人物 ID，少量常用玩家绰号只保存在游戏侧，不改写资料或凭昵称生成关系。异格绰号仍对应同一人物。维护入口、来源与匹配边界见 [GAME.md](../../../../docs/GAME.md)。

新访客默认普通模式，四种模式默认仅干员；已保存的自定义范围继续保留，旧六步存档校验后迁移到探索模式。新键 arknights-games-v2 保存四份独立规则、题目与进度，模式切换可恢复原题。资料指纹变化后保留各模式规则，重新出题；损坏缓存不阻止游玩。原键 arknights-six-links-v1 不删除。仅复用同一份全局进度的实现更短，但切换会丢题或把一种模式的状态误用于另一种，因此未采用。

结算通过原生可展开区提供多条真实有效路线。探索与输入模式按步数递增枚举六步内不重复人物的路线；普通模式保持给定人物不变，枚举本题候选的有效组合。参考路线数量与搜索次数有界，页面明确说明可能只列出部分结果；只有一条时如实显示，不能复制同一人物的不同形态冒充多条解。

异格在游戏中作为独立出场形象，共享正式人物 ID、关系、禁用和已访问状态。没有把它们扩成额外图节点，避免本体与异格互连、重复占步或绕过禁用。每次新题选择出场形象并单独保存，输入明确异格名称时可选用该中转形象，题目给定终点保持原形象。当前 38 个映射来自游戏角色表与正式人物别名，运行时仍要求正式人物和别名存在；不把条件叙事改判为普通关系。新素材在独立暂存目录生成，固定上游提交、记录来源和摘要，安装为新的固定资源版本，原素材和历史 dist 保留。

继续使用 CharacterIllustration.vue 与原来的布局断点，普通模式左侧跟随当前空位左边的人物，探索和输入模式左侧跟随当前人物，右侧固定终点。双人判断两侧显示本题的 A、B 人物，保留相同立绘和切换能力。手机竖屏保留并排双立绘与下方操作区，横屏保留左右布局。没有新建视觉系统、修改原立绘素材或引入搜索依赖。

验证由本机 make check、游戏算法测试、双人判断、三种连线模式浏览器检查及原六步交互回归覆盖，实际结果和未验证范围集中在 [GAME.md](../../../../docs/GAME.md)。该验证不代表真人可玩性、真实手机软键盘或可信服务端排名；后续引入每日统一题目、排名或同步时仍须重新评估服务端数据版本与成绩校验。本记录补充[原六步决定](2026-09-20-six-links-game.md)，保留其通行口径、资料方向与页面边界。
